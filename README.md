# grieks-diner

Een kleine React-app met één vraag: *Wil je met mij uit eten bij de Griek?* 🇬🇷

## Lokaal draaien

```bash
npm install
npm run dev
```

## Bouwen

```bash
npm run build     # output in dist/
npm run preview   # bekijk de build lokaal
```

## Hosting

Gehost op Vercel: importeer deze GitHub-repo op vercel.com — Vite wordt automatisch herkend.
Elke push naar `main` wordt automatisch opnieuw gedeployed.
